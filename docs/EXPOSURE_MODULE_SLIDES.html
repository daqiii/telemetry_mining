01 · The idea

One object per exposure — not per-script plumbing.

  • The problemEvery analysis hand-rolls its own file paths, raw SQL, and DATE-OBS parsing — copied, tweaked, and subtly different in each notebook.
  • The fixExposure(expid) is one object that lazily resolves every source tied to that exposure, through a single consistent API.
  • So analyses composeinstead of duplicating plumbing — and everyone shares the same hard-won gotchas and fixes.
e = Exposure(255020)

e.header          # raw FITS header
e.coords          # fiber coords, POS_LINPHI
e.db_row          # condensed DB record
e.calibstars      # std-star flux calib
e.time_window     # (start, end) UTC
...

# lazy + cached; degrades to DB-only

02 · Data sources

Everything about an exposure, unified.

Raw exposure directory

  • FITS header & coordinates (incl. POS_LINPHI)
  • ETC summary · guider centroids · fiberassign

Replicator database

  • condensed exposure.exposure record (tcs/hexapod blobs, airmass, tile…)
  • guider time series (telemetry.*)
  • the alarm log (alarms.alarms)

Offline reductions / QA

  • daily exposure row · exposure-table flags
  • GFA summary (seeing, transparency)
  • FIBERQA / PETALQA · cframe spectra · calibstars

Bring your own

  • TableSource — any EXPID-keyed table (e.g. WIYN seeing)
  • TelemetryField — named time-series lookups
Lazy & cached. Nothing is fetched until you touch it; each source is read once per exposure. File-based accessors fall back cleanly to DB-only when the on-disk files have been purged.

03 · Key functions

One exposure, or thousands.

  • Exposure(expid) — accessors.header .coords .db_row .calibstars .cframe_tables() .gfa_row .fiberqa_table .telemetry() .alarms() …
  • select_exposures(where, columns=…)one row per exposure matching a SQL WHERE; pull any field via a small column spec language. on_error='skip', max_workers=….
  • harvest(expids, fn, concat=True)run fn(Exposure) per exposure and pool per-fiber tables into one DataFrame — night resolved, EXPID inserted, gaps skipped, read in parallel.
  • time ↔ exposureExposure.time_window, Exposure.at_time(t), find_alarms(alarm_id=…) — attach any timestamped event to its exposure.
You write Python; the module builds and runs the queries (parameterized, identifiers validated) — no hand-written SQL in the notebook.

04 · Example — many exposures

Pool a per-fiber quantity across a whole survey window.

from telemetry_mining import select_exposures, harvest

sel = select_exposures(
    "sequence = ANY(%s) and night between %s and %s and totteff > %s",
    params=(['DESI'], 20260101, 20260710, 30.0))

def per_exposure(e):
    cs = e.calibstars
    if cs is None: return None            # -> harvest drops this exposure
    return cs.join(e.coords[['POS_LINPHI']], on=['PETAL_LOC','DEVICE_LOC'])

calib = harvest(sel.EXPID, per_exposure, concat=True, max_workers=8)
# -> ONE DataFrame: EXPID column, night resolved, gaps skipped, read in parallel
This is the actual calibstars_linphi study (are the “lin-phi” positioners biased?) — the answer came from grouping that one pooled frame by robot type.

05 · Example — the alarm log

Alarm 9200 (“large mount offset”): where do the episodes land?

from telemetry_mining import find_alarms, Exposure

alarms = find_alarms(alarm_id=9200)          # every occurrence, all years
alarms['expid'] = alarms.message.str.extract(r'DESI \((\d+)\)')[0]

def pointing(expid):
    tcs = Exposure(int(expid)).db_row['tcs']   # DB-only — works on purged old nights
    return tcs['mount_ha'], tcs['mount_dec']
# -> scatter of mount HA / Dec, coloured by episode (year)
Live demo: the alarm_9200_mount_offsets notebook — alarm search → exposure → mount pointing → episode map, entirely through the module (no SQL, no reading FITS files).
